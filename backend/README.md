# بک‌اند پرتال استانداری مازندران

پروژه مستقل **Laravel 13 / PHP 8.5 / MySQL 8** برای API سایت، پنل مدیریت و پرتال خدمات مردمی. هیچ فرانت‌اند، Vite، Node، Docker یا تصویر حجیمی داخل پروژه نیست. برنامه و تست‌ها از MySQL استفاده می‌کنند.

مبنای ماژول‌ها دو طرح ارسالی سایت و پنل است. محتوای واقعی سایت آنلاین استخراج یا وارد نشده است. داده‌های DemoSeeder، صریحاً آزمایشی‌اند.

## اجرای سریع روی مک

ابتدا MySQL محلی را روشن کنید و دیتابیس برنامه را با ابزار مدیریت MySQL یا دستور SQL زیر بسازید:

```sql
CREATE DATABASE IF NOT EXISTS ostandari CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

از داخل پوشه پروژه، برای نصب اولیه:

```bash
composer install
cp .env.example .env
```

مقادیر `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` در `.env` را با MySQL خود تنظیم کنید. اگر `.env` موجود دارید، همان فایل را ویرایش کنید. سپس:

```bash
composer setup
php artisan serve
```

آدرس پایه API:

```text
http://127.0.0.1:8000/api/v1
```

تست اتصال: `GET /api/v1/health`. مسیر `/` صفحه وب ندارد؛ این پروژه فقط بک‌اند است.

`composer setup` فایل `.env` و کلید برنامه را در صورت نیاز می‌سازد، migrationها را در دیتابیس MySQL تنظیم‌شده اجرا می‌کند، نقش‌ها و مدیر اولیه را ثبت می‌کند و لینک فایل‌های عمومی را می‌سازد. در محیط محلی، در پایان حساب درخواستی `admin / admin` را آماده می‌کند و توکن‌های قبلی همان حساب را باطل می‌کند. ایمیل پیش‌فرض `admin@ostandari.test` است. در محیط غیرمحلی، رمز قوی از `ADMIN_PASSWORD` برای ساخت اولیه استفاده می‌شود و دستور حساب محلی اجرا نمی‌شود.

برای محتوای نمونه شامل شهرستان‌ها، سازمان‌ها، اخبار سه‌زبانه، خدمات، مدیران، نظرسنجی و فرم نمونه:

```bash
php artisan db:seed --class=DemoSeeder
```

نصب وابستگی‌ها به اینترنت نیاز دارد؛ پس از نصب، اجرای حالت پیش‌فرض محلی به اینترنت یا سرویس پیامک نیاز ندارد. کدهای PHP، مایگریشن‌ها، تست‌ها و مستندات در ZIP هستند؛ `vendor`، دیتابیس محلی، رمزها و لاگ‌ها عمداً در بسته نیستند. `composer.lock` نسخه وابستگی‌ها را ثابت می‌کند.

## پیش‌نیازها

- PHP 8.5، Composer 2. محدودیت نسخه PHP در composer.json برابر `^8.5` است.
- MySQL 8.0 یا بالاتر؛ افزونه `pdo_mysql` برای PHP فعال باشد.
- `mbstring`, `openssl`, `fileinfo`, `ctype`, `curl`, `dom`, `xml`, `tokenizer`, `session`, `pdo` باید فعال باشند. `intl` و `zip` توصیه می‌شوند.
- پیش از نصب، با `php -v` فعال‌بودن PHP 8.5 در خط فرمان را بررسی کنید. اگر چند نسخه PHP نصب دارید، Composer و Artisan را هم با نسخه 8.5 اجرا کنید.
- اگر روی مک خطای `ext-intl` گرفتید، با `php --ini` فایل تنظیمات همان PHP خط فرمان را پیدا و افزونه را فعال کنید.

برای حجم کمترِ وابستگی‌های نصب‌شده، اگر اجرای تست‌ها لازم نیست:

```bash
composer install --no-dev --optimize-autoloader
composer setup
php artisan serve
```

## ورود مدیر

```bash
curl -X POST http://127.0.0.1:8000/api/v1/auth/login \
  -H 'Accept: application/json' -H 'Content-Type: application/json' \
  -d '{"login":"admin","password":"رمز نمایش‌داده‌شده هنگام setup"}'
```

مقدار `data.token` را در هدر درخواست‌های مجاز بفرستید:

```http
Authorization: Bearer YOUR_TOKEN
Accept: application/json
```

## ورود شهروند در حالت محلی

`POST /auth/otp/request` با `name`, `mobile`, `national_code` یک `challenge_id` می‌سازد. اگر `APP_ENV=local`, `OTP_DRIVER=log`, `OTP_EXPOSE_LOCAL=true` باشد، `dev_code` شش‌رقمی در پاسخ می‌آید. سپس `challenge_id` و `code` را به `POST /auth/otp/verify` بفرستید. ارقام فارسی و عربی برای این فیلدها پذیرفته می‌شوند.

این کنترل، اعتبار قالب کد ملی و مالکیت شماره از طریق OTP را پوشش می‌دهد؛ استعلام هویت از ثبت‌احوال/شاهکار پیاده نشده است. در محیط خارج از local/testing، درایور log کد ورود صادر نمی‌کند. برای ارسال واقعی، `OTP_DRIVER=http` و `SMS_ENDPOINT` امن، `SMS_TOKEN` و در صورت نیاز `SMS_SENDER` را تنظیم کنید. قرارداد درخواست در API.md آمده است. ایمیل پیش‌فرض نیز در `storage/logs/laravel.log` ثبت می‌شود؛ ارسال واقعی به تنظیم SMTP نیاز دارد.

`POST /assistant/query` پاسخ را از FAQ و محتوای منتشرشده برمی‌گرداند و منابع را مشخص می‌کند. **این موتور جست‌وجوی محلی است و به مدل زبانی خارجی وصل نیست.** حساب، هزینه یا کلید AI نمی‌خواهد و پاسخ ساختگی تولید نمی‌کند.

## MySQL

تنظیمات پیش‌فرض `.env.example` به شکل زیر است. نام دیتابیس و حساب اتصال را مطابق سیستم خود تغییر دهید:

```dotenv
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=ostandari
DB_USERNAME=root
DB_PASSWORD=
```

اگر نسخه قبلی را اجرا کرده‌اید، همین مقادیر را در `.env` موجود قرار دهید و پیش از `composer setup` دستور `php artisan config:clear` را اجرا کنید. داده‌های SQLite قبلی به‌صورت خودکار به MySQL منتقل نمی‌شوند. رمز شامل فاصله یا `#` را داخل کوتیشن قرار دهید. پورت و نام کاربری را از تنظیمات MySQL خود بگیرید.

## تست و کارهای دوره‌ای

برای تست، دیتابیس جداگانه زیر را در MySQL بسازید:

```sql
CREATE DATABASE IF NOT EXISTS ostandari_testing CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

```bash
cp .env.testing.example .env.testing
```

اطلاعات اتصال MySQL را در `.env.testing` تنظیم کنید؛ حساب اتصال باید روی `ostandari_testing` اجازه ایجاد و حذف جدول داشته باشد. این دیتابیس مخصوص تست است و جدول‌های آن هنگام تست بازسازی می‌شوند. `phpunit.xml` نام دیتابیس را به `ostandari_testing` محدود می‌کند و TestCase پیش از اجرای migration اتصال واقعی را کنترل می‌کند. سپس:

```bash
php artisan config:clear
composer test
```

زمان‌بند روزانه کدهای ورود و توکن‌های قدیمی منقضی‌شده را پاک می‌کند؛ دستور آن `php artisan schedule:run` است. برای توسعه محلی، اجرای دائمی زمان‌بند الزامی نیست؛ بررسی انقضا در خود API انجام می‌شود.

تاریخ ورودی API میلادی ISO 8601 و فیلد date فرم‌ها `YYYY-MM-DD` است. نمایش شمسی و تبدیل تاریخ انتخاب‌گر فارسی بر عهده کلاینت است. منطقه زمانی برنامه `Asia/Tehran` است. فرانت‌اند باید بعداً به این API متصل شود؛ فایل‌های HTML طرح تغییری نکرده‌اند.

## وابستگی‌های مستقیم

تنها بسته‌های زمان اجرا `laravel/framework`, `laravel/sanctum`, `ezyang/htmlpurifier` هستند. PHPUnit و Mockery فقط برای تست‌اند. هیچ بسته پنل آماده، رابط کاربری، Redis یا موتور جست‌وجوی جداگانه استفاده نشده است.

## حساب درخواستی مدیریت محلی و فرمانداری‌ها

در نسخهٔ همراه فرانت، `composer setup` در پایانِ اجرای محلی، حساب `admin / admin` را آماده می‌کند. برای دیتابیس موجود:

```bash
php artisan db:seed --class=CountySeeder
php artisan portal:local-admin
```

دستور دوم فقط در `local` و `testing` اجرا می‌شود، رمز همین حساب را بازنشانی می‌کند و توکن‌های قبلی‌اش را باطل می‌کند. مسیر داشبورد در فرانت `http://127.0.0.1:3000/admin` و مسیر ورود `http://127.0.0.1:3000/admin/login` است.

Seeder شهرستان‌ها، نام ۲۲ شهرستان و واحدهای فرمانداری را ایجاد می‌کند. نام‌هایی مانند `nur/noor` به یک رکورد می‌رسند. `POST /api/v1/contact` با `county_slug=nur` پیام را در واحد نور ثبت می‌کند. گالری عمومی نیز با `organization_id` فیلتر می‌شود.
