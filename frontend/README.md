# فرانت استانداری مازندران

پروژهٔ محلی با Next.js، TypeScript، Alpine.js و Tailwind CSS. صفحهٔ اصلی و قالب‌های سایت و پنل از دو ZIP ارسالی گرفته شده‌اند. برای مقصدهایی که طرح مستقل نداشتند، صفحه‌های هم‌تم اضافه شده است.

## اجرا

Node.js 24.15 یا جدیدتر از شاخهٔ ۲۴، یا Node.js 26 پشتیبانی می‌شود. بررسی این نسخه با Node.js 24.19.0 انجام شده است.

```bash
cd ostandari-frontend
npm ci
npm run dev
```

سایت: http://127.0.0.1:3000

مدیریت: http://127.0.0.1:3000/admin

ورود مدیریت: http://127.0.0.1:3000/admin/login

**نام کاربری: `admin` — رمز عبور: `admin`**

در اجرای تازه، `TEMPLATE_PREVIEW=true` است: قالب‌ها و محتوای نمونهٔ طراحی بدون Laravel باز می‌شوند. ورود مدیریت محلی، نشست واقعی با کوکی HttpOnly دارد. نوشتن در MySQL به اجرای بک‌اند و تنظیم حالت اتصال نیاز دارد؛ حالت نمایش طرح، ذخیرهٔ موفقِ ساختگی نشان نمی‌دهد.

## اتصال به Laravel و MySQL

بک‌اند همراه، Laravel 13 و PHP 8.5 است. اطلاعات MySQL در فایل تنظیمات بک‌اند قرار می‌گیرد.

برای بک‌اند تازه، دیتابیس MySQL را بسازید و مشخصات آن را در `.env` تنظیم کنید؛ سپس:

```bash
cd ../ostandari-backend
composer install
composer setup
php artisan serve --host=127.0.0.1 --port=8000
```

اگر دیتابیس نسخهٔ قبلی را دارید، این دو دستور رکوردهای شهرستان‌ها و حساب درخواستی را آماده می‌کنند:

```bash
php artisan db:seed --class=CountySeeder
php artisan portal:local-admin
```

دستور دوم رمز حساب `admin` را به `admin` تغییر می‌دهد و توکن‌های قبلی آن را باطل می‌کند. فقط در محیط `local` یا `testing` قابل اجراست.

در فرانت، `.env.example` را به `.env.local` کپی کنید و برای استفاده از دادهٔ واقعی قرار دهید:

```dotenv
BACKEND_URL=http://127.0.0.1:8000/api/v1
TEMPLATE_PREVIEW=false
COOKIE_SECURE=false
```

فرانت را دوباره اجرا کنید. همان `/admin/login` حالا از ورود Laravel و حساب MySQL استفاده می‌کند. حالت پیش‌فرض محلی فقط روی نشانی‌های loopback مانند `127.0.0.1` و `localhost` ورود `admin/admin` را می‌پذیرد.

## فرمانداری‌ها

۲۲ ناحیهٔ نقشه لینک مستقل دارند. نمونه:

http://127.0.0.1:3000/office?name=nur

همهٔ شهرستان‌ها از قالب مشترک، هدر، فوتر و بارگذاری دادهٔ واحد استفاده می‌کنند. نام شهرستان در پیوند اخبار، گالری و ارتباط با فرمانداری حفظ می‌شود. فرماندار یا خبرِ یک شهرستان برای شهرستان دیگر نمایش داده نمی‌شود. رکورد مسئول فعلی باید `kind=county_governor` و `is_current=true` داشته باشد.

خبرها و گالری با `organization_id` همان فرمانداری فیلتر می‌شوند. فرم تماس، `county_slug` را به بک‌اند می‌فرستد و پیام در واحد مربوط ثبت می‌شود. نام‌های قدیمی مثل `noor` و `gov_tonekabon` نیز پشتیبانی می‌شوند.

## فایل‌های طراحی و ساختار

تمام **۶۶۴ فایل اصلی**، با همان بایت‌های ZIPهای ارسالی، در `originals` حفظ شده‌اند. فایل‌های همراه سیستم‌عامل با پسوند `.bin` در `originals/archive-metadata` نگه داشته شده‌اند؛ مسیر اصلی و SHA-256 آن‌ها در `docs/original-designs.json` ثبت است.

۷۰ قالب اصلی به JSX تبدیل شده‌اند و نشانی‌های فایل HTML/HTM اصلی نیز برای دیدن قالب‌ها پشتیبانی می‌شوند. تصاویر، فونت‌ها، CSS و JavaScript اصلی در آرشیو حاضرند؛ فایل‌های اجرایی موردنیاز سایت در `public/design` هستند. اسکریپت‌های inline طرح در مرورگر اجرا نمی‌شوند و رفتارها با کنترلرهای Alpine مدیریت می‌شوند.

- `src/components/site`: هدر، فوتر، نقشه، فرم‌ها و اجزای مشترک سایت
- `src/features/site`: صفحات عمومی، قالب فرمانداری و اتصال داده
- `src/features/admin`: مدیریت فهرست‌ها، فرم‌ها و عملیات API
- `src/views`: قالب‌های تبدیل‌شده از فایل‌های ارسالی
- `src/lib/auth`: نشست مدیریت محلی و کنترل دسترسی مدیریت
- `src/app/api`: پراکسی Laravel و ورود محلی
- `src/styles/portal.css`: تکمیل چیدمان و نمایش واکنش‌گرا با تم اصلی

## ساخت و بررسی

```bash
npm run typecheck
npm test
npm run design:verify
npm run build
npm start
```

`npm run build` دارایی‌های `public` و `.next/static` را کنار سرور standalone قرار می‌دهد. پس از build، این روش نیز قابل استفاده است:

```bash
HOSTNAME=127.0.0.1 node .next/standalone/server.js
```

بستهٔ تحویل، سورس است؛ `node_modules`، `.next` و تنظیمات شخصی داخل ZIP قرار ندارند. برای نتیجهٔ تست‌ها و محدودیت بررسی تصویری، `docs/VERIFICATION.md` را بخوانید. مسیرهای جدید در `docs/ROUTES.md` آمده‌اند.
